
# Personal Portfolio Website

## About the Project
This is a personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my introduction, education, technical skills, projects, certifications, and contact information.

## Features
- Attractive and responsive user interface
- Personal introduction and profile photographs
- About Me section
- Technical skills and projects showcase
- Education and experience details
- Certifications section
- Contact and social media links
- Custom golden sparkle cursor
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Clone or download this repository.
2. Open the WebDev-L1-Portfolio folder.
3. Open `index.html` in your browser.
4. Explore the portfolio website.
