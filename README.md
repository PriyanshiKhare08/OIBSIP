# ÉLORA – Fashion Landing Page

ÉLORA is a modern and elegant fashion website landing page designed to showcase the latest fashion collections and trends.

## Features

- Elegant navigation bar
- Attractive hero section
- Women's Wear, Men's Wear and Accessories categories
- Trending products section
- Newsletter subscription interaction
- Responsive design for mobile and desktop
- Smooth scrolling and hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Explore the ÉLORA fashion website.
